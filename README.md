# DTO — Docs Trade Organization

Official website for **DTO (Docs Trade Organization)**, the Google Docs marketplace and exchange
created by BananaNetworkz.

## Pages

| File | Purpose |
|---|---|
| `index.html` | Home / overview |
| `how-it-works.html` | Buying, selling, DoxStox, shares, valuation process, mission |
| `doxstox.html` | The DoxStox formula + interactive calculator |
| `buyouts.html` | Real-money Full Doc Buyout system, 7% fee calculator, 9-step process |
| `listings.html` | Live listings table (filter / search / sort) |
| `join.html` | Listing request form that builds a prefilled email to DTO staff |
| `404.html` | Not-found page |

Static HTML/CSS/JS — no build step required to view, no server, no database, no cost.

## Adding or updating listings

Edit **`data/listings.json`** and commit. The listings page reads it at load time.

```json
{
  "name": "Doc name",
  "description": "One-line description",
  "type": "stock",          // "stock" or "buyout"
  "doxstox": 3025,           // DoxStox score
  "verified": true,
  "askingPrice": null        // USD number for buyouts, null for stock listings
}
```

Stock share price is derived automatically: `SP = DS / 100` (DTC per share).

## Editing page content

The HTML files are generated by `build.py`. Edit the strings in `build.py`, then run:

```bash
python3 build.py
```

## DoxStox formula

```
DS = 200I + 100P + 150R + 75G     SP = DS / 100
```

I = Influence (1–10) · P = Partners (1 pt each) · R = Reputation (0–10) · G = Growth (0–10)
